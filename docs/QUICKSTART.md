# 10分钟上手

“10分钟”指阅读与准备示例的建议时间，不是交付速度承诺。需要你已有可用的AI助手及相应文件/命令工具，本仓库不附账号或执行服务。

1. 阅读[方法](METHOD.md)及[能力边界](STATUS.md)。
2. 复制[任务合同](../templates/TASK.md)，写清一个范围小、可验证的任务；可先使用[订单示例](../examples/ORDER-REPORT.md)。
3. 将下面的完整要求连同合同交给已有AI助手。不要发送密钥或不必要的客户隐私。
4. 从任务开始计时。收到结果后按合同检查原始文件和验收回执；缺能力时记录缺口，不把推演算作已执行。
5. 保存[交付回执](../templates/RECEIPT.md)。只有需要现实故障接续时才配置已有成熟执行器、检查点和执行权机制；一段提示词不提供这些保障。

## 可直接使用的要求

> 请按《AI自动化组织V5》的公开方法完成所附合同。先明确输入、交付物、验收、成本与权限；优先复用已有成熟工具、模板、官方接口和已验证配方。检查输入到交付及主要异常后冻结方案，再完成现实执行与独立验收。普通故障最小修复并连续完成，保留已确认成果；未知提交先只读对账，避免重复副作用。仅在本次授权内行动。最终交付真实成品、验收证据、完整用时、成本、人工介入及未认证边界。没有实际执行权限或工具时明确缺失，不能声称已经完成或在后台运行。

## 如何比较两个方案

使用同一输入、质量、资源、成本和故障边界；记录从可执行合同到最终读回的全部时间。第一次建设与后续复用分开，不能把一方的完整工程时间与另一方的热态脚本时间比较。没有足够对照时只陈述本次成绩。
